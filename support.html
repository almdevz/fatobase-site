TikTok integration support

If a TikTok authorization is no longer desired, revoke the FatoBase authorization from the settings made available by TikTok. After revocation, the revoked authorization can no longer be used for future API requests.

Privacy and data requests

For questions about information processed by FatoBase, access revocation or data-deletion requests, send an email with the subject FatoBase Privacy Request. Please do not send passwords, access tokens or other secrets by email.

Response information

Support requests should describe the affected feature and, when relevant, the publication date or platform. Do not include credentials or confidential authentication data.
